## Things I did not change on purpose

- `FPackagePrecacheInfo::~FPackagePrecacheInfo` leaks `PatchSynchronizationObject` like the exe (rva 0x19c00).
- `ArkBsPatch`'s `OutBufferLen = newsize + 1` is stored as `PackageDataSize` like the exe (agent C's warning); `FBufferReaderWithSHA`
  simply sees a one-byte-longer buffer.
- `ULinkerLoad::FixupExportMap`, `CreateActiveRedirectsMap` and the `WITH_MULTI_THREADED_COMPRESSION` code stay in the files
  (uncalled / compiled out) rather than being deleted — smaller diff against the reference.
- `UObject::SerializeScriptPropertiesBin` has a NULL guard the exe lacks (documented in the comment).
