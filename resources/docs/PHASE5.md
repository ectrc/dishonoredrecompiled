# Phase 3 wave 3 — milestone 3 and the first frame (PHASE5.md)

Written 2026-09-25 after wave 2 (`PHASE4.md`) landed. Plan of record: `PLAN.md`. Read `STATUS.md` first
(incident note, current run state). Letters continue wave 2 (O–V used): packages **W–AC**.

## Goal of this wave

Wave 2 left us with an exe that loads every native script package and dies decoding the first
animation. This wave turns that into **a running engine with a window**:

1. **Milestone 3**: `Startup.upk` loaded, `GEngine->Init()` completes, the `EngineTick` loop runs
   headless (`-nullrhi`), and `LoadMap DishonoredGameFull_P` gets as far as the game module allows.
2. **First frame**: window + D3D9 device + cooked shaders on the device + clear/present; the Bink
   startup movies behind `DISHONORED_WITH_BINK` if the movie player port fits.
3. **Ground work for milestone 5**: Engine per-function convergence starts; GameFramework/IpDrv bases
   and the pending asserts close; the DishonoredGame natives the startup path hits get ported.

User decisions (2026-09-25): Edge animation is **bypassed** this wave (reference pose) and ported next
wave; the retail class set stays (no ini swap to stock UE3 classes) — native stubs **warn once and
return zero** and agents port what the path hits; scope includes first frame, map load, Engine
convergence and GameFramework/IpDrv hygiene.

The retail 2013 exe is the target; every port cites a 2013 rva (named db `retail2013_named.i64`)
and uses the 2012 decompile only as the readable version of the same function.
