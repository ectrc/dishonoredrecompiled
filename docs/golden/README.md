# Golden logs

Reference `Launch.log` captures used by the smoke test (`tools/normalize_log.py` produces the
`*.norm.log` variants that are diffed).

## 2012 — `2012_arkprofile_launch.log`

Produced 2026-09-24 from `Dishonored_Debug2012\Binaries\Win32` with:

```
DishonoredGame-ArkProfile.exe -log -seekfreeloadingpcconsole -nosteam -windowed -ResX=1280 -ResY=720
```

* `-seekfreeloadingpcconsole` is required: the generated `DishonoredEngine.ini` points
  `SeekFreePCPaths` at `CookedPC`, but the content lives in `CookedPCConsole`. Without the flag
  startup dies with `Failed to find file for package Core for async preloading`.
* `DishonoredGame-Shipping.exe` and `DishonoredGame-Shipping-DC.exe` write **no** `Launch.log`
  even with `-log` (logging is compiled out of the Shipping configs). The ArkProfile build logs
  fully and is the reference from now on. Its `Init:`/`Log:` lines up to the main menu are the
  target for milestones 1–3.
* Reaches `LoadMap: DishonoredGameFull_P?Name=Corvo?Team=255` and
  `Bringing World DishonoredGameFull_P.TheWorld up for play` in ~4 s (main menu map).
* 84 `Error: ImportText ... Unknown member` lines come from the `Dishonored*.ini` files in
  `Dishonored_Debug2012\DishonoredGame\Config`, which were generated by the 2013 build and
  contain fields (`m_bShowMapNameOnlyOnXboxNoHDD`, `MissionNumber`, DLC05–07 entries) the 2012
  classes do not have. Harmless for the reference run; delete the generated `Dishonored*.ini`
  files to regenerate clean 2012 ones if a noise-free log is wanted.

## 2013 — `2013_retail_launch.log`

Copied from `%USERPROFILE%\Documents\My Games\Dishonored\DishonoredGame\Logs\Launch.log`.
The retail Shipping exe only logs savegame statistics (`FLevelSaver`, `m_ObjectDictionary`), so
this file is 19 lines and useless as a startup reference. The 2012 ArkProfile log is the
startup golden; the retail log is kept only to document what the Shipping config emits.
